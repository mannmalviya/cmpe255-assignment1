# Data Science Skills Mastery Lab — recreated assignment

This fixes the reference lab's catalog/coverage mismatch by defining one concrete demonstration for all **46 unique installed skills** (15 ML/MLOps + 31 analytics).

## Use

```bash
cd 05_data_science_skills_lab
python verify_manifest.py
```

Then paste [STARTER_PROMPT.md](./STARTER_PROMPT.md) into a fresh Codex session in this directory. The installed skills become discoverable on the next turn/session.

The manifest uses eight popular Kaggle benchmarks: Titanic, House Prices, Credit Card Fraud, Brazilian E-Commerce by Olist, Marketing A/B Testing, Store Sales, IMDb Reviews, and Netflix titles.

No result values are prefilled: the assignment requires measured artifacts and explicitly forbids synthetic results being presented as Kaggle findings.
